# Движок авто-дизайна «Обставь» — архитектура, каталог, правила

Версия 0.1 · 18.11.2026 · черновик для разработки.

Цель: по планировке комнаты, стилю, назначению и списку нужной мебели выдать 5 разных, физически корректных вариантов интерьера из реальных товаров маркетплейсов, с чертежами и ведомостью.

Главный принцип: **нейросеть не расставляет мебель «на глаз».** Расстановку делает детерминированный алгоритм по измеримым правилам (сантиметры, зоны, проходы). Языковая модель только подбирает товары из каталога под стиль/бюджет и объясняет выбор. Рендер строится из той же 3D-сцены, что и чертежи, поэтому картинка не «врёт» по размерам.

Все числа ниже — **стартовые справочные значения** (эргономика жилых помещений, общепринятые в дизайне интерьера). Их нужно вынести в конфиг и настраивать по результатам пилота на 20–30 реальных комнатах.

## 1. Общая схема (конвейер)

```
[1] Ввод комнаты ─► [2] Анализ геометрии ─► [3] Программа помещения
                                                   │
[4] Каталог ──► [5] Подбор товаров (стиль, бюджет) ┘
                                                   ▼
                       [6] Генерация расстановок (правила + поиск)
                                                   ▼
                       [7] Проверка жёстких правил ─► отбраковка
                                                   ▼
                       [8] Оценка мягких правил ─► рейтинг
                                                   ▼
                       [9] Отбор 5 разных лучших вариантов
                                                   ▼
        [10] Электрика и свет по мебели ─► [11] Чертежи, ведомости, рендер
                                                   ▼
                       [12] Логи выбора пользователя (обучение весов)
```

### [1] Ввод
- Контур комнаты: многоугольник в см (MVP — прямоугольник), высота потолка.
- Стены: толщина; помеченные «несущая / перегородка» (на будущее для перепланировки).
- Двери: позиция на стене, ширина полотна, сторона петель, направление открывания (внутрь/наружу, левая/правая), тип (распашная/раздвижная/проём).
- Окна: позиция, ширина, высота подоконника, высота окна, тип открывания (створка внутрь — нужна зона), балконная дверь.
- Препятствия: радиаторы (длина, глубина, высота), стояки, короба, колонны, ниши.
- Существующие точки электрики (если есть): ввод, щиток, имеющиеся розетки.
- Опросник: назначение комнаты, стиль, бюджет на мебель, кто живёт (один/пара/ребёнок/подросток), обязательная мебель (кровать, шкаф, рабочее место, ТВ…), пожелания (размер кровати «не меньше 160», «нужен туалетный столик»), ведущая рука для рабочего места (опционально).

### [2] Анализ геометрии
Вычисляем из ввода:
- **Сегменты стен** с длинами.
- **Запретные зоны** (никакой мебели):
  - сектор открывания двери: четверть круга радиусом = ширина полотна + 5 см;
  - зона прохода у двери: прямоугольник ширина двери × 80 см с обеих сторон проёма;
  - зона открывания створки окна внутрь: ширина створки × (ширина створки + 10 см);
  - зона доступа к окну: ширина окна × 60 см перед окном (мебель ниже подоконника допустима, см. правила W);
  - зона перед радиатором: 10 см (воздух), низкая мебель не ближе 10 см, высокая — не перекрывает.
- **Свободные отрезки стен** — куда можно ставить мебель «спиной к стене» (стена минус проёмы минус запретные зоны), с пометкой «под окном» / «между окном и углом» / «напротив двери».
- **Главный путь движения**: от двери к окну и к каждой другой двери. На следующих шагах проверяем, что он остаётся проходимым (см. правило C1).
- **Естественный свет**: направление от окон (для рабочего места и зеркал).

### [3] Программа помещения
Шаблон по назначению комнаты превращает опросник в список **функциональных групп** с приоритетом:
- MUST — без неё вариант не показываем;
- SHOULD — сильно желательно, при нехватке места выкидываем с пометкой «не поместилось: …»;
- NICE — если осталось место.

Пример «Спальня, пара»:
| Группа | Состав | Приоритет |
| --- | --- | --- |
| Кровать | кровать 160–180 + 2 тумбочки | MUST |
| Хранение одежды | шкаф, ≥ 1,2 м штанги на человека (≥ 2,4 м на пару) | MUST (можно уменьшить до 1,8 м с пометкой) |
| Комод | комод 80–120 | SHOULD |
| Рабочее место | стол 100–120 + стул | по опроснику |
| ТВ | ТВ на стене/тумбе напротив кровати | по опроснику |
| Туалетный столик | столик 80–100 + пуф | NICE |
| Кресло для чтения | кресло + торшер | NICE |

### [4] Каталог — см. раздел 2.

### [5] Подбор товаров
- Языковая модель получает опросник + **только список товаров из каталога** (по категориям, с тегами стиля, ценой, габаритами) и возвращает **ранжированные кандидаты** на каждую позицию программы. Модель **не придумывает товары и размеры**.
- Лучше на старте: **готовые стилевые наборы** (кураторские «киты»): «Сканди светлый до 150 тыс.», «Современный графит до 300 тыс.» — в каждом по 2–4 варианта на позицию разных размеров (кровать 140/160/180 одной линейки). Модель выбирает набор и подходящие размеры, расстановщик проверяет.
- Бюджет: сумма цен ≤ бюджета × 1,0; мягкий штраф за перерасход до 10 %, жёсткий отказ выше.

### [6] Генерация расстановок
Иерархически, от главного к второстепенному:
1. **Выбор якорной стены** для главного предмета (кровать — изголовьем, диван — спинкой, стол — к окну/боком к окну). Перебираем все свободные отрезки, где помещается группа целиком.
2. **Выбор размера** главного предмета: от наибольшего допустимого к меньшему (раздел 4.1 — формулы).
3. **Установка группы как единого блока** (кровать + тумбочки — шаблон с фиксированными смещениями).
4. **Второстепенные предметы** — на оставшиеся отрезки стен, с шагом 5 см по позиции, ориентация «спиной к стене»; отдельные предметы (кресло, стол) — допускаются «от стены» по своим правилам.
5. **Поиск**: лучевой поиск (beam search) или имитация отжига по пространству «стена × позиция × размер × товар». Для прямоугольной комнаты 10–15 м² пространство небольшое — перебор за доли секунды.

Каждый предмет в сцене — это **тело** (габарит товара) + **зоны обслуживания** (раздел 3). Правило пересечения:
- тело ∩ тело — нельзя;
- тело ∩ зона другого предмета — нельзя;
- зона ∩ зона — можно, если это не одновременно используемые зоны (зона перед шкафом может совпадать с проходом; зона выдвижения стула не может совпадать с зоной открывания двери).

### [7] Жёсткие правила — отбраковка (раздел 4, помечены H).
### [8] Мягкие правила — штрафы/бонусы с весами (раздел 4, помечены S). Итоговая оценка = Σ вес × оценка правила. Веса — в конфиге, потом подбираются по выборам пользователей.

### [9] Отбор 5 вариантов
Из топ-50 по оценке берём 5 **разных**: расстояние между вариантами = разная якорная стена главного предмета, разный размер главного предмета, разный набор групп (с рабочим местом / без), разная стилевая линейка. Жадный отбор: лучший → следующий лучший с расстоянием ≥ порога от уже выбранных.

### [10] Электрика и свет — выводятся из мебели (раздел 5).
### [11] Выход
- Координаты всех предметов → существующий конвейер чертежей (план мебели, электрика, свет, полы, потолки, развёртки, ведомости).
- Рендер: 3D-сцена → базовый рендер/глубина/контуры → Gemini как «улучшатель» (img2img), а не генерация с нуля. Так геометрия и мебель на картинке совпадают с планом.

### [12] Обратная связь
Логировать: какой вариант выбран, какие предметы заменены и на что, что сдвинуто и на сколько, переходы по ссылкам, покупки (если есть партнёрка). Раз в месяц — подстройка весов мягких правил.

### 2.2. Нормализация размеров (самое важное для «влезет ли»)
- Габарит **тела** = максимальный по выступам: ножки, подлокотники, изголовье, ручки.
- Кровати: номинал (матрас) ≠ габарит. Если в карточке только номинал — добавлять по умолчанию +8…+15 см к ширине и +10…+20 см к длине и ставить уверенность «оценка».
- Диваны: габарит в сложенном и разложенном виде; глубина сиденья.
- Шкафы: глубина корпуса + ручки; тип и ширина дверей.
- Столы: размер в сложенном и разложенном виде.
- ТВ: из диагонали: ширина ≈ 0,87 × диагональ, высота ≈ 0,49 × диагональ (16:9) + рамка.
- Источники: таблица характеристик карточки (приоритет) → текст описания → фото с размерами (ручная проверка). Еженедельная выборочная сверка 10 позиций (ops.md).
- Товар без уверенности «проверено / из таблицы» — не использовать в авто-дизайне или показывать с пометкой «сверьте размер».

## 3. Модель пространства (как «видит» движок)

- Сетка 5×5 см (или точная геометрия многоугольников, сетка — для проверки прохода).
- Слои: стены · проёмы · запретные зоны · тела · зоны обслуживания · путь движения.
- Каждое правило — функция над слоями, возвращает «нарушено/нет» (жёсткое) или число 0…1 (мягкое).
- **Проверка прохода**: на сетке строим путь «агента» шириной 60 см (комфорт 70–80) от двери ко всем зонам доступа (каждая сторона кровати, фронт шкафа, окно, рабочий стул). Алгоритм: дилатация тел на 30 см + поиск пути (BFS/A*). Нет пути — вариант отбрасывается.

### 4.1. Спальня
**Выбор размера кровати — формулы.** Пусть:
- `Lh` — длина свободного отрезка стены под изголовье;
- `Bw`, `Bl` — ширина и длина тела кровати (по каталогу);
- `T` — ширина тумбочки (40–50), `A` — проход с каждой стороны (≥ 60);
- `R` — расстояние от изголовья до противоположной стены (глубина комнаты в этом направлении).

Условия для двуспальной кровати с доступом с двух сторон:
- **По ширине:** `Lh ≥ Bw + 2·A` → при A = 60: кровать 160 (тело ≈170) требует ≥ 290 см; 180 (≈190) — ≥ 310 см; 140 (≈150) — ≥ 270 см.
  (Тумбочки стоят в зоне прохода у изголовья и не уменьшают проход по длине кровати, но `T ≤ A` — иначе тумбочка выступает в проход.)
- **По длине:** `R ≥ Bl + F`, где `F` — что у изножья:
  - пусто/проход: `F ≥ 70` → `R ≥ ~285` (при Bl ≈ 215);
  - комод/ТВ-тумба глубиной 40–50 + проход 70: `R ≥ ~335`;
  - шкаф распашной глубиной 60 + зона 85: `R ≥ ~360`; шкаф-купе 60 + 65: `R ≥ ~340`.

Алгоритм выбора: перебрать размеры от желаемого (опросник) вниз: 200 → 180 → 160 → 140 → 120; взять наибольший, при котором выполняются H-правила и C1; если ни один — пробуем кровать с доступом с одной стороны (только для 120/140 и только если опросник не «пара») — иначе «двуспальная кровать не помещается, предлагаем 140 у стены / диван-кровать».

### 4.4. Обеденная зона / кухня (на этапе 3)
- Стол: на человека 60 см по краю × 40 см глубины; стол на 4 — ≥ 80×120 или Ø 100.
- Зона за стулом: 75 для сидящего; 90–110, если за спиной ходят.
- Кухня: «рабочий треугольник» мойка–плита–холодильник, сумма сторон 360–660 см, каждая сторона 120–270; проход между рядами 120–150; между плитой и окном/холодильником/краем ≥ 30–40; мойка — ближе к стояку (уклон канализации — ограничение по расстоянию, уточнить с сантехником); столешница 85–92.
- (Кухня — отдельный модуль, у неё свои правила по коммуникациям. Начинать не с неё.)

## 5. Электрика и свет, выводимые из мебели

Справочные значения для бытового дизайна; финальная схема — на согласование с электриком (не нормативный документ).

| Предмет | Точки | Высота от чистого пола |
| --- | --- | --- |
| Кровать двуспальная | по 2 розетки с каждой стороны над тумбочкой + выключатель/бра с каждой стороны | розетки 60–75 (выше тумбочки на 10–15), выключатели 70–90 |
| Вход в комнату | выключатель со стороны ручки, 10–15 см от наличника | 80–90 |
| Рабочий стол | 3–4 розетки + интернет | 75–90 (над столешницей) или 20–30 под столом |
| ТВ | 3–4 розетки + ТВ + интернет за телевизором | 110–130 (скрыто за экраном) |
| Туалетный столик | 2 розетки (фен) | 90–100 |
| Общие розетки (уборка) | по 1 у каждой свободной стены через 3–4 м | 30 |
| Кухня | по технике + над столешницей | 105–115 (фартук), техника — по паспорту |

Правила:
- E1: розетка не за шкафом/комодом (кроме специально для встраиваемой техники).
- E2: розетка не в зоне открывания двери.
- E3: выключатели у входа — на стороне открывания ручки.
- E4: проходной выключатель у кровати + у входа, если в спальне общий свет.
- Свет: ориентир освещённости для жилых комнат ≈ 150 лк, кухни ≈ 150 лк, санузла и коридора ≈ 50 лк (уточнить по актуальному СП). Число светильников = (площадь × лк) / световой поток одного светильника × коэффициент 1,2–1,5. Привязка светильников к выключателям: общий свет — у входа; бра — у кровати; подсветка рабочей зоны — у стола.

## 6. Как проверять качество

- **Набор эталонов:** 20–30 реальных комнат (в т. ч. ручные дизайны первого ЖК), для каждой — 1–2 расстановки, сделанные человеком.
- **Метрики:**
  - 0 нарушений H-правил (автотест);
  - доля вариантов, которые эксперт/пользователь называет «пригодными» ≥ 70 % (порог пилота из launch.md);
  - хотя бы 1 из 5 вариантов совпадает по логике с эталоном;
  - время генерации 5 вариантов ≤ 10 с;
  - ни одного товара с уверенностью размеров «нет».
- **Регрессия:** любое изменение правил — прогон по всему набору эталонов.

## 8. Чего НЕ делать
- Не давать языковой модели координаты мебели — только выбор из каталога и объяснения.
- Не генерировать картинку «с нуля» по описанию — только поверх 3D-сцены.
- Не показывать вариант, если хоть одно H-правило нарушено.
- Не использовать товар с непроверенными размерами без предупреждения.
